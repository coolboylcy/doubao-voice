# 语音狗子品牌策略

## 一句话定位

给需要在任何 macOS App 里用语音代替打字的人：按住右 Option 说话，松手，文字出现在光标处。

## 品牌故事

「语音狗子」是开发者做给女朋友的。她叫小狗子，用 AI 写代码时要不停解释需求，打字很累。他希望她一开口，字就落在光标处。这只狗于是被做出来：在本机听懂话，不联网，不登记，不收费。它不是效率指标，只是一句顺手说出口的话。

## 调性与语气规范

### 怎么说话

- 用动作和结果说话：按住、说话、松手、上屏、落在光标处。
- 一次讲清事实：离线、免费、Apple Silicon、250 MB、10 秒预热、2 分钟上限。
- 保留笨拙和具体，不包装成“效率革命”。
- 承认边界：要授权、要等预热、会取消、不是云端服务。
- 像介绍一件已经放在桌上的礼物，不像发布会。

### 不这么说话

- 不用“颠覆、赋能、极致、重塑、解放双手、提升 300%”。
- 不堆模型名词、架构名词、工程名词。
- 不把“女朋友”讲成撒娇文案，只讲清楚它从哪里来。
- 不使用科技蓝紫、冷感玻璃、未来感、极客黑话。
- 不请求关注、不暗示升级、不制造焦虑。

### 正反例

| 不这么说 | 这么说 |
|---|---|
| 一键唤醒 AI 语音引擎，重塑输入体验。 | 按住右 Option，说完松手，字就出现。 |
| 极速启动，秒级响应，畅享无缝识别。 | 首次启动约 10 秒，让它把模型摆好。 |
| 全场景智能语音助手，效率提升 300%。 | 编辑器、终端、聊天框、浏览器输入框都能用。 |
| 端到端低延迟本地推理架构。 | 识别在你本机完成，不联网。 |
| 小狗子爱你，快下载吧！ | 它一开始就是做给小狗子的。 |

## 视觉方向

### 色彩

- 品牌主色：暖黑 `#241F1B`
- 品牌辅色：奶油米 `#EADCC5`
- 强调色：苔绿 `#536B5A`
- 深色模式强调色：浅苔绿 `#88B29A`
- 取消 / 错误：砖红 `#A44A3E`
- 浅色背景：米白 `#F7F3EE`
- 深色背景：近黑 `#141210`

用法原则：

- 文字和结构用暖黑或近黑，不用纯黑 `#000000`。
- 奶油米用于底色、卡片、吉祥物，不做大面积高亮。
- 苔绿只用于下载、录音状态、明确可点击元素。
- 深色模式下，强调色变浅，避免刺眼；背景不要纯黑，保持暖灰。

### 字体

使用系统字体栈，不引入外部字体。

推荐字体气质：

- 中文：系统无衬线，优先 PingFang SC / Hiragino Sans GB / Microsoft YaHei。
- 英文与数字：SF Pro / Segoe UI / system-ui。
- 标题：600 字重，短，不夸张。
- 正文：400 字重，行高 1.6 左右。
- 技术事实可用等宽字体，如 `ui-monospace, SFMono-Regular, Menlo, Consolas`，但只用于短信息，如 `250 MB`、`10s`、`2min`。

不用装饰字体、手写体、像素体、未来感字体。

### 圆角与留白

- 卡片圆角：`16px`
- 主按钮圆角：`999px`，做成柔软胶囊，不用尖锐矩形。
- 小控件圆角：`8px`
- 图标与吉祥物轮廓保持圆润，不做硬折角。
- 页面只保留一个主行动：下载。
- 首屏不堆按钮，不做轮播，不做滚动动画，不做粒子背景。
- 一屏讲完产品、故事、下载、边界。
- 留白优先于装饰。元素之间宁可空，也不要解释性图标。

### 为什么这样定

奶油米对应 3D 黏土质感的小狗，像桌面摆件，不像软件 UI。

暖黑像纸和墨，适合表达“文字落在光标处”。

苔绿不是常见科技色，也不像警告色。它更像安静存在的信号：在听、可以按、正在识别。

整体要“温”，但不能甜；要“可爱”，但不能幼稚；要“礼物感”，但不能朋友圈化。

## 吉祥物设定

### 名字与性格

- 正式名字：狗子
- 产品名来源：「语音狗子」
- 昵称：小狗子
- 性格：温、笨、可靠、不主动打扰。它像趴在桌边等一句话的小狗，不抢镜头，不表演。

### 基础形态

- 高度抽象的小狗，不指向真实品种。
- 正面端坐，重心稳定。
- 头是圆润几何体，身体像蛋形，四肢短粗。
- 垂耳贴脸侧，不尖、不立起，耳尖到脸颊。
- 眼睛为黑色圆眼，不画高光、睫毛、眼线。
- 鼻头为深色小圆点，配简洁嘴线。
- 尾巴短小，低伏或自然垂。
- 无衣服、项圈、帽子、道具，避免复杂。
- 造型保持“光滑哑光的 3D 黏土质感”，有柔和棚拍光影，有轻微环境反射，但不做高光斑。

### 色彩与材质

- 主体奶油米：`#EFE3D0`
- 耳内与阴影：`#D8C6A8`
- 眼睛：`#151210`
- 鼻头与嘴线：`#322A26`
- 身体高光：`#F8F1E5`
- 环境阴影：`#C9BBA6`
- 纸片：`#FFFFFF`
- 纸片线：`#9B9188`

材质：哑光黏土，表面平滑，边缘柔和。不做毛绒、金属、玻璃、塑料光泽。

### 状态

1. **趴着待命**
   - 前爪并排贴地，胸口靠近地面，头低约 10 度。
   - 双耳自然下垂，眼睛圆睁，嘴线短平。
   - 用于默认、未录音、成功、取消后的安静状态。

2. **竖起耳朵在听**
   - 双耳向斜后方抬起约 25 度，头微微前伸。
   - 身体略挺，鼻头朝前，眼睛保持圆眼。
   - 用于录音中、持续录音中、菜单栏状态。

3. **歪头思考**
   - 身体不动，头向左或右歪 18 度。
   - 一只耳略抬，另一只耳自然垂，嘴线短弧。
   - 用于首次启动预热、权限说明、错误说明。

4. **叼着文字送过来**
   - 嘴含一张圆角小纸片，纸片上有三条灰线。
   - 头略低，双耳下垂，前爪分开，尾巴微微抬起。
   - 用于识别完成、文字上屏、下载后的感谢提示。

### 出现位置

- 官网首屏：右侧静态出现，默认“趴着待命”，不抢下载按钮。
- 下载按钮附近：不放置动效，不放大，不遮挡主行动。
- App 首次启动：使用“歪头思考”，表示引擎预热约 10 秒。
- 录音中：菜单栏图标或浮层使用“竖起耳朵在听”。
- 短按持续录音：保持“竖起耳朵在听”，再按结束。
- 松手上屏：短暂出现“叼着文字送过来”，随后回到“趴着待命”。
- 按 Esc 取消：回到“趴着待命”，不弹失败插画。
- 权限引导：使用“趴着待命”，配合短说明。
- Release 页或关于页：可作为小尺寸头像，只出现一次。
