它看起来不太聪明，但字会送到。

它一开始，
就是做给小狗子的。

「语音狗子」是开发者做给女朋友的。她叫小狗子，用 AI 写代码时要不停解释需求，打字很累。他希望她一开口，字就落在光标处。这只狗于是被做出来：在本机听懂话，不联网，不登记，不收费。它不是效率指标，只是一句顺手说出口的话。

三步，
说完就走。

不需要唤醒词，也没有对话框。光标在哪里，字就去哪里。

  1. 按住右 Option

    长按 ⌥ 右，底部波形出现，它就在听。

  2. 照常说话

    一次最多 2 分钟。录音中按 Esc，这次就不算。

  3. 松手

    它想一下，文字自动出现在当前光标处。

它只在这台 Mac 上听。

没有账号，没有 API Key，也没有音频上传。第一次打开会慢一点，是它在把随 App 带来的模型摆好。
