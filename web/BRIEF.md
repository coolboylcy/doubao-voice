# 设计任务书：语音狗子官网

## 产品是什么

macOS 上的全局语音输入。**按住右 Option 说话，松手，文字直接出现在光标处**——
任何 App 都能用：写代码的编辑器、终端、聊天窗口、浏览器输入框。

硬事实（不要编，也不要夸大）：

- 识别全程在本机完成。不联网、不要账号、不要 API Key、完全免费
- 模型随 App 携带（FunASR SenseVoice，242 MB），所以安装包约 250 MB
- 要求 Apple Silicon Mac、macOS 13 以上
- 从 GitHub Releases 下载 DMG，拖进 Applications，授权三项系统权限即可用
- 首次启动约 10 秒预热识别引擎
- 单次录音上限 2 分钟
- 开源，MIT 协议

交互只有三个：

- 按住右 Option 说话，松手上屏
- 短按右 Option 进入持续录音，再按一下结束
- 录音中按 Esc 取消

## 品牌故事（这是灵魂，不要弄丢）

这个工具是**开发者做给女朋友的**。

女朋友的昵称叫「小狗子」。她在做 vibe coding——用 AI 写代码，需要不停地打字
描述需求、解释想法、纠正 AI。手很累。

所以他做了这个：让她可以直接说话。

「语音狗子」这个名字就是这么来的。

这决定了整个品牌不是一个效率工具的口吻。它不该谈「提升 300% 输入效率」，
不该堆技术名词，不该用那种科技公司的冷感。它是一份礼物，语气应该是日常的、
温的、带一点笨拙的可爱——像一只在旁边趴着等你说话的小狗。

但也**不要腻**。不要通篇撒糖，不要把故事讲成朋友圈文案。克制地讲一次，
讲清楚就够了，剩下的让产品本身说话。

## 硬性要求

**极简。极简。极简。** 这是最高优先级：

- 没有用的交互一律砍掉。不要轮播图、不要滚动动画秀、不要粒子背景、
  不要「回到顶部」按钮、不要 FAQ 手风琴、不要社交媒体图标墙
- 一屏能讲完的不要两屏
- 能不加的按钮就不加。整个页面的主行动只有一个：下载
- 文案能删一半就删一半

技术约束：

- **单个静态 HTML 文件，完全自包含**：CSS 和 JS 全部内联，不引用任何外部
  资源（没有 CDN、没有 Google Fonts、没有外部图片）。用系统字体栈
- 深色与浅色都要好看，跟随系统 `prefers-color-scheme`
- 手机上也要能正常看
- 不要任何追踪、统计、cookie

## 需要你产出两个文件

### 1. `web/brand.md` — 品牌策略

要包含：

- **一句话定位**：看完就知道这是什么、给谁用
- **品牌故事**：正式的对外版本，克制、动人、不超过 150 字
- **调性与语气规范**：怎么说话、不怎么说话，各给几个正反例
- **视觉方向**：主色、辅色（给出具体色值）、字体气质、圆角与留白的原则、
  为什么这样定
- **吉祥物设定**：这只狗叫什么、什么品种或形态、性格、有哪几个状态
  （至少要有：趴着待命 / 竖起耳朵在听 / 歪头思考 / 叼着文字送过来），
  以及它在产品里出现在哪些位置。描述要具体到能照着画出来

### 2. `web/index.html` — 官网单页

按你定的品牌规范实现。吉祥物先用占位（画个简单的 SVG 或留出带注释的位置），
形象稿会另外生成后替换。

下载按钮指向 `https://github.com/coolboylcy/voice-doggo/releases`。

结果，而不是先做页面再补说辞。
